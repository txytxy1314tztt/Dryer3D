1. 首次并行运行构建和单测时，pnpm 在无 TTY 环境中因模块目录竞争失败。改为串行运行后解决。
2. 首次构建因缺少 CSS 类型引用和直接 `@types/three` 声明失败。补充类型声明后通过。
3. Playwright 自带浏览器 revision 与本机缓存不匹配。未下载新浏览器，改用已安装的系统 Chrome。
4. E2E 首次断言因两个同名标题产生严格选择器二义性。收紧为场景标题后解决。
5. E2E 捕获 Drei `Html` 标签在机型切换时的 React 19 DOM 卸载竞态。阶段 1 移除该门户标签，保留网格高亮和参数联动；最终控制台错误检查通过。
